# PDF QA Backend

This is the FastAPI backend for the PDF Genie application. It handles PDF processing, OCR, and vector search using Pinecone.

## Tech Stack
* **Framework:** FastAPI
* **Database:** Supabase (PostgreSQL)
* **Vector Store:** Pinecone
* **Deployment:** Hugging Face Spaces (Docker)
